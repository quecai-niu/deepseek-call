### API 参数格式（已修正）

```json
{
  "model": "deepseek-v4-pro",
  "messages": [...],
  "stream": true,
  "thinking": {"type": "enabled"},
  "reasoning_effort": "high"
}
```

注意：`reasoning_effort` 是顶层参数，不嵌套在 `thinking` 中。

## 问题排查记录

### 问题：用户设置了模型和思考等级，但问模型时模型不知道

**根因**：system prompt 是静态字符串 `'你是一个有帮助的AI助手。'`，模型名称、思考模式、effort 这些作为 API 参数传入，不进入对话上下文。模型在对话中看不到自己的配置信息。

**修复**：`SYSTEM_PROMPT` 从常量改为 `buildSystemPrompt()` 函数，动态拼接当前配置：
- 基础身份描述
- 当前模型名称（从 SettingsStore 读取）
- 思考模式开关状态
- 推理深度等级（仅开启思考时）

修复后用户问"你是什么模型？""你的推理深度是多少？"模型可以正确回答。
